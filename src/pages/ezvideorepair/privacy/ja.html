適用範囲とお問い合わせ

このポリシーは、Karl Luo（whitelok）が開発する Mac 用アプリ EZVideoRepair の公式サイト版と Mac App Store 版、およびこのページに適用されます。2026年11月25日更新。プライバシーに関するお問い合わせは whitelok@gmail.com までお願いします。

素材はこの Mac で処理されます

選択した動画、画像、音声トラックのデコード、AI による修復、書き出しは、ご利用の Mac 上で行われます。アプリが素材、修復結果、推論に使う入力を開発者やクラウドの推論サービスに送信することはありません。モデルの学習にも使用しません。

Mac に保存する情報

プロジェクトの保存、結果の再利用、中断した修復の再開のため、アプリは素材のパス、ファイルのハッシュ値、メディアの仕様、修復設定、タスクの状態、修復結果、再開用データ、ファイルへのアクセス権を記録したブックマークを Mac に保存します。言語設定、モデルフォルダの場所、ダウンロード状況も Mac に保存されます。ハッシュ値は Mac 上での照合と再利用に使われ、開発者には送信されません。書き出したプロジェクトには素材名、パス、修復設定、結果、再開用データが含まれる場合があります。共有する前に内容をご確認ください。

モデルのダウンロードと外部サービス

EZVR Flash V1 または EZVR Flash V2 の重みファイルのダウンロードを選ぶと、アプリは macOS の地域設定に基づいて配信元を選択します。中国本土（CN）では第三者のミラーサイト hf-mirror.com、それ以外の地域では Hugging Face に HTTPS で接続します。どちらもファイル配信サービスに転送される場合があります。地域の判定に IP アドレスは使いません。表示言語も配信元に影響しません。配信元は、接続に必要な IP アドレス、リクエストの時刻、要求されたモデルファイル、標準的なネットワークリクエスト情報を受け取ります。取り扱いと保存期間は各サービスのプライバシーポリシーに従います。素材、修復結果、素材のローカルパスは送信されません。保存済みの対応モデルを使う場合、ダウンロードは不要です。モデルの準備後はオフラインで修復できます。アプリを終了するとダウンロードも停止します。

任意の利用統計

利用統計の共有は初期設定でオフです。設定でオンにすると、Google Analytics for Firebase で、読み込み、モデルの準備、プレビュー、修復、書き出し、プロジェクトの保存と読み込みの結果を記録します。記録項目には、モデルと素材の種類、操作、結果とその取得方法、省メモリ設定、あらかじめ定めたエラー分類と所要時間の区分が含まれます。開発者は修復が成功または失敗する工程を把握するためにこれらの情報を利用します。

Google が自動的に収集する情報

Google は、アプリインスタンス ID、利用可能な場合は Firebase インストール ID、アプリとシステムのバージョン、デバイスの機種、言語、初回起動、セッション、利用時間を記録することがあります。接続時の IP アドレスからおおよその地域を推定する場合もあります。広告 ID、ベンダー ID、広告のパーソナライズ、画面の自動記録は無効です。素材、サムネイル、ファイル名、パス、プロジェクト名、ファイルのハッシュ値、生のエラー内容、ハードウェアやタスクの識別子は統計に含まれません。アカウント登録は不要です。個人情報を販売することはありません。

共有をオフにする

オフラインでは、同意後に収集したイベントをこの Mac に一時保存し、接続が復旧してから送信することがあります。設定でいつでも共有をオフにできます。収集が停止し、Mac 上の統計データが消去され、アプリインスタンス ID がリセットされます。送信済みのデータは削除されません。モデルの準備ができていれば、共有がオフの場合や Analytics に接続できない場合でも修復と書き出しができます。

Mac App Store 版

アカウント登録は不要です。広告や行動分析、トラッキング用の SDK は使用していません。利用履歴やクラッシュレポートを開発者に自動送信することはなく、個人情報を販売することもありません。macOS と App Store 自体の診断、購入、配信に関する情報は、Apple のポリシーとお使いのシステム設定に従って管理されます。

保存期間とデータの管理

プロジェクト、結果、再開用データ、モデルは、通常、ご自身で削除するまで Mac に残ります。設定の「キャッシュを消去」で削除されるのは一時キャッシュです。モデル、プロジェクト、結果、再開用データは保持されます。ローカルモデルとの関連付けを解除しても、選択したモデルファイルは削除されません。元の素材や、保存したプロジェクトと書き出し結果は Finder で管理できます。アプリの作業領域、ダウンロード済みモデル、状態データは、ユーザのライブラリ内の Containers/…/Data/Library にあります。アプリを終了して必要なファイルをバックアップした後、該当するデータを削除できます。削除すると、関連するタスクの記録や修復を再開するための情報が失われます。アプリをアンインストールしても、サンドボックス内のファイルやご自身で書き出したファイルがすべて削除されるとは限りません。

メールまたは GitHub でサポートを依頼した場合、利用したサービスと開発者は、返信や問題の解決に必要なアドレス、本文、添付ファイルを受け取ります。不要な個人の素材は送信しないでください。連絡の記録は問題の解決と必要なフォローアップが終わるまで保管します。法令により保存が必要なものを除き、メールで削除を依頼できます。本ポリシーのページでは、分析スクリプト、広告、第三者のフォントを読み込みません。GitHub Pages のホスティング事業者は、アクセス元 IP アドレスなどのサーバーログを処理する場合があります。
