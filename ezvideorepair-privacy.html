隐私政策

适用范围与联系

本政策适用于 Karl Luo（whitelok）开发的 EZ视频修复助手（亦称 EZVideoRepair）Mac 应用，以及本隐私政策页面。更新日期：2026 年 10 月 29 日。隐私问题可联系 whitelok@gmail.com。

素材只在本机处理

你选择的视频、图片和音轨在 Mac 本机进行解码、AI 修复和导出。应用不会将这些素材、生成结果或模型推理输入上传给开发者或云端推理服务，也不会将其用于训练模型。

本地保存的信息

为提供项目保存、结果复用及断点继续，应用在本机保存素材路径、文件摘要、媒体规格、修复参数、任务状态、结果、断点和访问授权书签。语言偏好、模型目录和下载状态也保存在本机。文件摘要用于本地校验与复用，不会上传给开发者。导出的项目可能包含素材名称、路径、修复参数、结果及断点；分享项目前请检查其内容。

模型下载与外部服务

主动下载 EZVR Flash V1 模型时，应用根据 macOS 的地区设置选择下载源：中国大陆（CN）通过 HTTPS 访问第三方镜像 hf-mirror.com，其他地区访问 Hugging Face；两者均可能重定向至文件分发服务。应用不通过 IP 定位确定地区，界面语言不会影响下载源。这些服务会接收到建立连接所需的 IP 地址、请求时间、所请求的模型文件及标准网络请求信息；具体处理和保留方式由服务方的隐私政策约定。请求不包含你的素材、修复结果或本地素材路径。使用已有本地模型可以不进行模型下载；模型准备完成后，修复可离线进行。退出应用会停止应用的下载任务。

账户、分析与追踪

应用不要求注册账户，不接入广告、行为分析或追踪 SDK，不向开发者自动发送使用记录或崩溃报告，不出售用户个人信息。macOS 与 App Store 自身的诊断、购买和分发信息受 Apple 的政策及你的系统设置管理。

保留、清理与控制

本地项目、结果、断点及模型通常保留到你主动删除。设置中的“清理缓存”只清理临时缓存，不删除模型、项目、结果或断点。解除本地模型关联不会删除你选择的模型源文件。你可以在 Finder 中管理自己保存的原片、项目和导出结果；应用沙盒内的工作区、下载模型和状态数据位于用户资源库的 Containers/com.whitelok.mac.EZVideoResolutionRepairer/Data/Library 内。退出应用并备份所需文件后，可删除相应本地数据；这会失去相关任务记录或继续修复能力。卸载应用不保证同时删除所有沙盒或用户导出文件。

主动联系与网页访问

如果你通过电子邮件或 GitHub 主动寻求支持，相关服务和开发者会收到你提交的地址、文字及附件，用于回复和处理问题；请避免发送不必要的私人素材。支持通信保留至处理完问题及必要的后续沟通，删除请求可通过邮箱提出，依法必须保留的记录除外。本政策页面不加载分析脚本、广告或第三方字体；发布到 GitHub Pages 后，网站托管方仍可能处理访问 IP 等服务器日志。

安全、儿童与政策更新

应用使用 macOS 沙盒和用户授予的文件访问权限；网络下载使用 HTTPS。请保护你的设备，并留意系统备份或云同步可能另行保存本地文件。应用不面向儿童专门设计，也不主动向儿童收集个人信息。如对信息访问、更正或删除有疑问，请通过上述邮箱联系；仅保存在设备上的信息需由你在设备上管理。政策发生变化时将在此页面及后续应用版本中更新日期和内容。
